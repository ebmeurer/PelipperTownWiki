# Third-party notices

## Stardew Valley — runtime UI sprites, trainer sprite, and Pokémon Chest recolor

The companion menu draws Stardew Valley's installed `MenuTiles`, `Cursors`, and
`Cursors_1_6` textures at runtime through the game's public menu surfaces. The
outside-game UI preview tool can also decode those three XNB files from the
user's own installation into a Git-ignored local cache for visual QA. No
Stardew UI texture is checked into this repository or packaged by that tool.
The extraction helper does not grant redistribution rights to the artwork;
do not publish or bundle its generated cache files.

The packaged `assets/npcs/trainer_joey.png` and the selectable sheets under
`assets/npcs/trainer_candidates/` are mechanical composites of Stardew Valley's
installed farmer base, skin, shirt, hairstyle, pants, and hat layers.
`tools/build_trainer_joey_sprite.py` and `tools/build_trainer_candidates.py`
select and recolor those layers, then arrange the standing and walking poses as
normal 64-by-128 NPC sheets. These are derivative Stardew Valley artworks. The
build tools and local ownership of the game do not grant redistribution rights;
confirm that distribution is permitted before bundling the generated sprites.

The packaged `assets/items/pokemon_chest_stardew.png` is a direct,
pixel-preserving recolor of Stardew Valley's standard Chest sprite (big
craftable sprite index 130 in `TileSheets/Craftables`). The original silhouette,
shading layout, metal bands, and latch are unchanged; only the wood-color ramp
is remapped to a red lid and white lower box. This is derivative Stardew Valley
artwork. The recolor does not grant redistribution rights to the underlying
sprite; confirm that distribution is permitted before bundling it.

The packaged `assets/items/mega_band_stardew.png` is a pixel-preserving crop
and palette edit of Stardew Valley's Elvish Jewelry object sprite (object ID
104 in `Maps/springobjects`). `tools/build_mega_band.py` retains the bracelet
silhouette and shading while remapping its metal and gem colors into the Mega
Band. It is derivative Stardew Valley artwork, and the same redistribution
warning applies.

## Pokémon Mystery Dungeon: Explorers of Sky — chore effects

The packaged `assets/effects/bulbasaur/chore_effects.png` is a mechanical atlas conversion of move-effect data from CHUNSOFT's *Pokémon Mystery Dungeon: Explorers of Sky*, inspected through [`pret/pmd-sky`](https://github.com/pret/pmd-sky). It contains these five animation sequences from `files/EFFECT/effect.bin`:

- Vine Whip lash: effect ID 194, archive entry 131, sequence 0;
- Vine Whip impact: effect ID 675, archive entry 131, sequence 1;
- Razor Leaf startup: effect ID 296, archive entry 108, sequence 9;
- Synthesis: effect ID 271, archive entry 125, sequence 0;
- Water Pulse projectile: effect ID 303, archive entry 81, sequence 8.

The SIR0/WAN files were decoded with the open-source [`skytemple-files`](https://github.com/SkyTemple/skytemple-files) format implementation. The image geometry and sequence frames come from the game data. Some effects reference shared runtime palette slots which aren't embedded in their individual WAN file; their preview colors were reconstructed as chore-appropriate green, blue, or gold ramps before the frames were assembled into the transparent runtime atlas.

These are official game graphics. The decompilation and extraction tools do not grant redistribution rights to the underlying artwork. Confirm that your use is permitted before distributing a build containing the atlas.

The same source and caveats apply to the reusable grids under `assets/effects/types/`. Their accompanying `type_effects.json` records the exact move ID, effect ID, `effect.bin` archive entry, animation sequence, grid layout, and timing for each of the 17 pre-Fairy Pokémon types. The selected moves are Swift, Flamethrower, Bubble, Thunderbolt, Magical Leaf, Ice Shard, Aura Sphere, Sludge Bomb, Earth Power, Air Cutter, Psybeam, X-Scissor, Stone Edge, Shadow Ball, Dragon Pulse, Dark Pulse, and Flash Cannon. `tools/prepare_pmd_type_effects.py` performs the mechanical conversion and applies type-appropriate fallback ramps when a WAN references palette slots supplied only at runtime.

The 36 move-aware grids under `assets/effects/extra/` are extracted from the same `effect.bin` source and carry the same redistribution caveat. They include physical hits, projectiles, target impacts, status clouds, source auras, barriers, drains, and complete multi-stage Ember, Fire Blast, and String Shot timelines. `extra_effects.json` retains the exact move/effect/archive/sequence mapping, source timing and offsets, logical origin, transparent frames, palette notes, and runtime presentation metadata; `tools/prepare_pmd_extra_effects.py` performs the reproducible conversion.

Palette-index transparency is materialized as alpha; Super Potion reuses the authored potion indices with the upstream `super_potion.pal`, the fossil icons use their matching Kanto, Hoenn, Old Amber, Skull, Armor, Jaw, and Sail palettes, and the 18 type Slates reuse the authored Plate indices with each upstream type palette, matching pokeemerald-expansion's own item mapping. The Normal Plate reuses the neutral Iron Plate art and palette. Wild Incense uses Full Incense art; Alolan and Galarian Incense are deterministic turquoise/coral and blue/magenta palette variants of that same pixel art. DexNav uses Poké Radar art. VS Seeker preserves Melan’s `vs_seeker.png` with `vs_seeker.pal`; Max Revive uses `max_revive.png` with the shared `revive.pal`, matching the upstream item palette mapping. The two RGBA sheets under `assets/ui/move_type_*.png` preserve the upstream Gen 8-style frame order and pixels: 32-by-16 symbol-and-abbreviation badges for rows/details, and 16-by-16 compact symbols for equipped slots. `tools/import_melan_items.py` performs both imports. The healing station importer renders Melan's FRLG Pokémon Center layout and copies the authored 32-by-29-pixel healing machine without changing its proportions into a two-tile Stardew furniture sheet. The local conversion adds a one-pixel lower outline sampled from the machine's existing side outline and a two-step translucent ground shadow so the standalone furniture sits naturally in Stardew scenes. Its 32-frame effect preserves the upstream Poké Ball glow art and 2-by-3 offset pattern, anchored to the six green wells in the extracted machine so the standalone furniture visibly fills from top to bottom before pulsing. The separate FRLG monitor effect belongs to the Pokémon Center's wall display and is intentionally not composited into the machine. Thrown capture balls reuse their matching inventory icon while normalizing their display scale to the original in-game ball size. The unmodified 16-by-16 battle-animation ball remains in the source tree as an excluded reference and is not packaged. The pokeemerald Bulbasaur file is likewise retained only as an excluded development input and is not the packaged overworld sprite.

No older `melan_gen4` or PurpleZaffre-pack assets are included.
