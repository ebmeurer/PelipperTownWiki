# Pelipper Town 1.2.6 Release Notes

- Fetch outdoors or inside breeding Barns. Pokémon wait one second before
  catching an airborne frisbee; water landings drift slowly toward shore.
- Switch Giratina between Standard and Origin forms from its Commands page.
- Find level-45 Meloetta at the Beach on Winter 15–17, including the Night Market.
- Read Meloetta and Giratina entries in Marlon's Legendary Field Guide.
- Quality and quantity passives work with bombs, Auto-Grabbers, Pokémon helpers,
  and Automate. Machine-speed passives apply to repeat and refilled cycles.
- Tooltips preserve authored line breaks and repeated lines.
- Farmhand sync errors explain the cause and how to reconnect.
- Pokémon requests appear on Help Wanted 0.9.3's expanded board.
- Carried frisbees return to their owner when changing maps.
- Every quest NPC reacts to shiny, legendary, and shiny legendary donations.
- Fixed Willy's unfilled player name in rare Pokémon dialogue.
- Dialogue and menus stay readable if translation files are missing or broken.

All multiplayer players must install 1.2.6. This build uses protocol 19;
update the host and every guest together.

See [the changelog](../CHANGELOG.md) for earlier changes.
