## Remaining patterns

Gardevoir, Arcanine, Lucario, Stoutland, Raichu, Roserade, and several other species still reach ten owners. Many are core partner choices, so this review preserves them rather than replacing them solely to flatten counts. Early-stage counts also combine branching evolutions: Eevee and Ralts can be frequent without their owners having identical final teams.

The candidate builder picks the first valid combination in authored order; this favors early candidates. Reviewed substitutions run after selection, preventing freed capacity from immediately filling with the same popular species elsewhere. This is an authoring rule, not runtime randomization.
